# Telegram Utility Bot

Личный Telegram-архив на aiogram 3. Бот принимает текст, ссылки и Telegram-медиа в личном чате, сохраняет копию там же и даёт искать и разбирать сохранённое через одно редактируемое inline-меню.

## Запуск локально

1. Скопируй `.env.example` в `.env`.
2. Укажи `BOT_TOKEN`, свой Telegram ID в `ALLOWED_USER_IDS` и `OWNER_USER_IDS`.
3. Установи Python-зависимости: `pip install -r requirements.txt`.
4. Запусти `python main.py` или `Запустить бота.bat` в Windows.

## Развёртывание на Render

- Используй Web Service с runtime **Docker**; образ собирается из `Dockerfile` в корне проекта.
- Добавь значения из `.env` в Environment. Для безопасного доступа задай `ALLOWED_USER_IDS` и `OWNER_USER_IDS`.
- Мини‑приложение обслуживается тем же Web Service по `/miniapp/` и использует тот же SQLite‑каталог. Render автоматически передаёт публичный HTTPS‑адрес через `RENDER_EXTERNAL_URL`; отдельный сервис, домен или платный план не нужны.
- Для уже созданного Web Service используй Docker runtime и запусти deploy. Сохрани `BOT_TOKEN`, `ALLOWED_USER_IDS`, `OWNER_USER_IDS`, `RENDER_FREE_MODE`, `DATABASE_PATH`, `HOST`.
- `DATABASE_PATH` указывает на SQLite-файл. В бесплатном Web Service файловая система временная: Render стирает SQLite при redeploy, перезапуске и spin-down. UptimeRobot не делает диск постоянным. Для сохранения данных между деплоями нужен платный compute и Persistent Disk, см. инструкцию ниже.
- Для AI-обработки сохранённых материалов задай `CHATGPT_AI_URL=https://tgshoppe.onrender.com/internal/utilbot/process` и `CHATGPT_AI_TOKEN`. В SIWC-сервисе `tgshoppe` задай `UTILBOT_AI_TOKEN` с тем же секретом. Результат сначала показывается как предложение: описание и теги заменяются только после нажатия «Принять замену»; «Оставить как есть» закрывает предложение, «Попробовать ещё» генерирует новое, «Отменить анализ» восстанавливает предыдущее состояние. Для обычных записей краткое описание заменяет прежний текст в карточке. Для пересланных сообщений оригинал, ссылка и автор сохраняются, AI добавляет только короткую пометку.
- Для расшифровки голосовых добавь `GROQ_API_KEY` в Environment UtilBot. В карточке голосового появится кнопка «Расшифровать и добавить теги»: сначала будет показана полная расшифровка и новые теги, и только после подтверждения они применятся. Исходная голосовая запись останется в архиве.
- Бот сохраняет URL скрытых гиперссылок из Telegram entities и показывает ссылку в карточке; архивная Telegram-копия пересланного сообщения сохраняет исходные ссылки и подпись автора.
- Health endpoint: `/health`. UptimeRobot может раз в несколько минут обращаться к нему, чтобы будить бесплатный Web Service.

## Как работает архив

- Отправленный в личный чат материал бот копирует в тот же чат, затем удаляет исходное сообщение. Если сохранить не получилось, исходник остаётся. Команды и временный текстовый ввод (например, название папки, запрос поиска или тег) удаляются после обработки, чтобы в чате оставались архивные копии и интерфейс бота.
- Перед сохранением бот проверяет повтор: для файлов сравнивает Telegram `file_unique_id`, для текста — нормализованный текст или ссылку. При совпадении повторную копию не создаёт и предлагает открыть уже сохранённую запись.
- Telegram хранит сами копии и файлы; SQLite на хостинге хранит индекс, папки, статусы, напоминания и ссылки на сообщения.
- Главное меню и списки редактируют одну закреплённую по `message_id` панель. Для просмотра медиа используется одно заменяемое превью.
- После потери SQLite бот не умеет перечитать историю чата через Bot API. Ответь `/restore` на последнюю резервную копию, чтобы вернуть каталог и связи с файлами.

## Резервные копии

- Автоматический снимок SQLite отправляется владельцу в этот же Telegram-чат; интервал `BACKUP_INTERVAL_HOURS` ограничен 24–48 часами и по умолчанию равен 24 часам.
- Пустая база после перезапуска Render не затирает старую копию: сначала восстанови предыдущую командой `/restore`.
- Для ручного снимка отправь `/backup`. Не удаляй сообщение с файлом бэкапа.
- Для восстановления ответь `/restore` именно на сообщение бота с файлом снимка. Рабочая база будет заменена содержимым выбранного снимка.
- Это защищает каталог на момент последней копии. Записи, сделанные после неё, могут потребовать повторного сохранения, хотя сами сообщения с файлами остаются в чате.

### Постоянное хранение на Render

Бесплатный Web Service не поддерживает Persistent Disk. Для постоянной SQLite-базы:

1. До изменения тарифа отправь `/backup` и дождись файла бэкапа в Telegram.
2. Переведи Web Service на платный compute-план Render.
3. В Render открой **Disks** и добавь диск с mount path `/var/data`.
4. В **Environment** задай `DATABASE_PATH=/var/data/bot.sqlite3`.
5. После деплоя ответь `/restore` на сохранённый файл бэкапа, чтобы перенести текущий архив на новый диск.

Если остаёшься на бесплатном плане, проверь `/status`: автоматический backup должен быть включён и иметь получателя. Перед каждым ручным деплоем сначала отправляй `/backup`, а после него при необходимости делай `/restore`. Это снижает риск потери последних изменений, но не заменяет постоянный диск.

## Меню и функции

- **Входящие**: новые материалы до разбора; можно разобрать их по одному, сразу выбрать папку или удалить запись, после чего откроется следующий материал.
- **Поиск**: поиск по тексту и сохранённым метаданным; кнопку «Поделиться из архива» можно нажать в личном чате, выбрать собеседника и найти материал прямо в его чате.
- Для личного OCR картинок настрой `CHATGPT_OCR_URL` на HTTPS endpoint ChatGPT-бота `/internal/ocr/image` и одинаковый случайный секрет в `CHATGPT_OCR_TOKEN` UtilBot и `UTILBOT_OCR_TOKEN` ChatGPT-бота. Кнопка доступна только владельцу и только для фото или архивных JPEG/PNG/WebP; байты передаются на распознавание отдельным запросом и не добавляются в историю чата.
- **На потом**: отдельный список отложенных материалов.
- **Избранное**: быстрые закладки.
- **Папки**: создать папку кнопкой и разложить материалы.
- **Напоминания**: напомнить о материале позже. При повторе бот удаляет предыдущее уведомление и оставляет в чате только последнее; при завершении, удалении или переносе удаляет и его. Уведомления, отправленные до включения этого учёта, автоматически удалить не получится.
- **Случайная находка**: открыть случайный материал из архива.
- **Ещё**: список всех файлов, RSS-ленты и помощь.
- **Мини‑приложение**: визуальный архив с поиском и фильтрами; можно открыть материал, посмотреть фото и контекст, выбрать несколько записей и разом переместить их, изменить тег или статус, добавить/убрать избранное либо удалить с подтверждением.
- Карточка показывает основные действия: статус, избранное и «Ещё действия». В дополнительных действиях доступны тег, напоминание, контекст и inline-поделиться.
- Удаление материала удаляет запись каталога, её контекст и по возможности архивную копию в Telegram. Telegram ограничивает удаление сообщений по времени; если старую копию удалить нельзя, она может остаться в чате.
- У сохранённой копии фото/файла кнопки «Переместить» и «Добавить тег» доступны сразу, без открытия карточки.
- Кнопка «Добавить контекст» сохраняет короткую заметку ответом на архивную копию в чате; контекст отображается в карточке и участвует в поиске.
- RSS/Atom-ленты проверяются примерно раз в 15 минут; публикацию можно сохранить вручную.
- Inline-поиск настраивается в `@BotFather` командой `/setinline`. В меню архива кнопка «Поделиться из архива» сама открывает выбор собеседника, а в карточке материала кнопка «Отправить в другой чат» сразу предлагает именно этот материал. После выбора результата Telegram отправляет его в открытый чат.
- Кнопка «🗃 Открыть архив» появляется в меню, когда задан HTTPS `MINI_APP_URL` или Render установил `RENDER_EXTERNAL_URL`. Открывать приложение нужно из Telegram: API проверяет подпись `initData` и allow-list пользователя.
- UptimeRobot продолжает обращаться к `/health`; этот же web-сервис отдаёт мини‑приложение и API. На бесплатном Render первый запрос после простоя может ждать пробуждения сервиса.

## Команды

- `/start` — открыть меню.
- `/help` — подсказка.
- `/status` — состояние бота, каталога и бэкапа.
- `/backup` — сделать снимок сейчас.
- `/restore` — восстановить базу в ответ на сообщение с бэкапом.

## Ограничения

- Доступ ограничивается Telegram ID из `ALLOWED_USER_IDS`/`OWNER_USER_IDS`.
- Telegram-копии — источник файлов; SQLite — индекс. Bot API не позволяет боту автоматически пересканировать старую историю чата.
- Резервирование раз в сутки оставляет окно, в котором новый индекс может потеряться при аварии. Сразу после важной большой загрузки можно вручную вызвать `/backup`.

## Если `/start` молчит

- Проверь логи Render: если команда пришла от пользователя вне allow-list, бот теперь пишет предупреждение про `ALLOWED_USER_IDS` и `OWNER_USER_IDS`; если polling стартовал, будет строка `Starting Telegram polling`.
- Если команда вообще не появляется в логах, проверь, что Web Service запущен и что не запущена вторая копия бота с тем же токеном. Telegram допускает только один активный long-polling процесс на токен.
- При старте приложение удаляет настроенный webhook, сохраняя очередь обновлений, потому что этот проект работает через long polling.

## Turso Cloud

Turso can be used as the active database with `DATABASE_BACKEND=turso`. Set `TURSO_DATABASE_URL` and `TURSO_AUTH_TOKEN` in the environment. Use `scripts/import_sqlite_to_turso.py` to import an existing SQLite snapshot into a new, empty test database; the source snapshot is left unchanged. The importer refuses to overwrite a non-empty database unless `--replace-existing` is explicitly supplied.

## Telegram Secretary bot

The optional secretary bot runs beside UtilBot in this same Render service. In Render → `gembabot` → Environment, add `SECRETARY_BOT_TOKEN` with the token from BotFather for the new bot, and `SECRETARY_OWNER_USER_ID` with your numeric Telegram user ID (the same ID used in `OWNER_USER_IDS`). Keep the existing `BOT_TOKEN` unchanged. The secretary's recent-chat list and timed actions use the currently configured database, including Turso when `DATABASE_BACKEND=turso`.

After deployment, start a private chat with the new bot and press Start. In Telegram's Business settings, connect this bot and select the chats it may manage; grant message reply/edit and delete permissions if Telegram offers them. A chat appears in `/chats` after the secretary has received a message from it. In a connected private chat, send `.mute`, `.typing 30min`, `.type текст`, `.del 100 текст`, `.spam 5 текст`, `.hack`, `.flip текст`, or `.tiny текст` directly. The command message is edited or deleted as the first Telegram action; Telegram may still display it briefly while that request is in flight. In the secretary bot's private chat, use `/chats` to choose a target and then send the same dot command as a fallback.

This feature does not connect to the SIWC/ChatGPT bot. It uses a separate BotFather token and a separate Telegram polling loop inside the existing UtilBot process.
